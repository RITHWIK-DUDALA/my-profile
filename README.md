# D Rithwik Satya — Personal Portfolio & Engineering Website

A high-performance portfolio website built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and modern web graphics / animation libraries (**OGL**, **Lenis**, **GSAP**).

## 🚀 Overview

- **Role**: AI & Machine Learning Engineer
- **Focus**: Intelligent systems, mathematical modeling, deep learning architectures, robotics simulation, and end-to-end intelligent pipelines.
- **Institution**: Amrita Vishwa Vidyapeetham, Chennai

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Graphics & Animation**: [OGL](https://github.com/oframe/ogl), [GSAP](https://greensock.com/gsap/), [Lenis](https://lenis.darkroom.engineering/) Smooth Scroll
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript

## 📂 Project Structure

```text
├── public/              # Static assets, portfolio images, and media
├── src/
│   ├── app/             # Next.js App Router pages and layouts
│   ├── components/      # UI components (home, nav, footer, sections)
│   ├── data/            # Site data, projects, research, and capabilities
│   ├── styles/          # Global styles and design system definitions
│   └── types/           # TypeScript interfaces and type definitions
```

## 💻 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

4. **Build for production**:
   ```bash
   npm run build
   ```
